# Persian-Suicide-Risk-Detection-using-NLP
This project focuses on binary text classification for detecting suicide-related and non-suicide Persian texts using Natural Language Processing (NLP) and Machine Learning/Deep Learning techniques.
The pipeline includes comprehensive Persian text preprocessing, feature extraction, model training, hyperparameter optimization, and performance evaluation. Multiple classification models were implemented and compared to identify the most effective approach for suicide risk detection.

## Key Features
* Persian text preprocessing (normalization, tokenization, stop-word removal, stemming/lemmatization)
* Feature extraction using TF-IDF and contextual language representations
* Training and evaluation of multiple machine learning and deep learning models
* Hyperparameter optimization for improved classification performance
* Comprehensive performance analysis using Accuracy, Precision, Recall, F1-score, and Confusion Matrix
* Explainable and reproducible NLP pipeline for Persian suicide risk detection

The primary objective of this project is to support the early identification of suicide-related content in Persian social media and textual data, providing a foundation for developing AI-assisted mental health monitoring systems.
